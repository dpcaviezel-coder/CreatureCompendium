CreatureCompendium
CreatureCompendium is a C# console application designed to store, search, and manage a collection of creatures.

Features
Add Creatures
Remove Creatures
Edit Creatures
Search By Name
Search By First Letter
Search By Habitat
Search By Type
Search By Rarity
Save To JSON
Load From JSON
Type Matchup Calculator
Damage Calculation
Concepts Practiced
Object-Oriented Programming
Collections
CRUD Operations
Enums
JSON Serialization
JSON Deserialization
LINQ
Search and Filtering
Composition

Future Improvements

Status Effects

Purpose
This project was created as part of a C# learning journey and serves as the foundation for a larger creature encyclopedia and management application.
